# 「仅链接可见文章 (Unlisted Post)」设计方案

---

## 一、 需求背景与目标

为博客系统引入一种**“未公开列出 / 仅链接可见”**的文章类型，满足私密分享与小范围传阅需求：

1. **未登录访客访问主页**：列表**不显示**该文章。
2. **管理员登录后访问主页**：列表**显示**该文章，并带有专属标识。
3. **通过分享链接访问**：任何人（未登录访客 / 已退出登录的管理员）均可**直接打开并阅读文章**。
4. **范围收敛**：仅聚焦**文章阅读、权限控制与主页展示**（不涉及评论与附件下载）。

---

## 二、 核心数据模型

沿用现有 `article` 表结构，无需执行 DDL 改表，直接扩展 `status` 字段取值：

| `status` 值 | 状态定义 | 主页可见性（未登录） | 主页可见性（管理员已登录） | 链接直接访问（未登录） | 搜索引擎与 RSS |
|---|---|---|---|---|---|
| **0** | 草稿 (Draft) | ❌ 隐藏 | ❌ 仅后台列表可见 | ❌ 404/1001 | ❌ 不收录 |
| **1** | 已发布 (Published) | ✅ 公开展示 | ✅ 公开展示 | ✅ 允许访问 | ✅ 收录 |
| **2** | 已归档 (Archived) | ❌ 主页不突出 | ❌ 主页不突出 | ✅ 允许访问 | ✅ 归档可见 |
| **3** | **仅链接可见 (Unlisted)** | **❌ 隐藏** | **✅ 显示（带专属徽章）** | **✅ 允许访问** | **❌ noindex / 拒收录** |

---

## 三、 系统链路与详细设计

### 1. 文章详情读取 (`GET /api/v1/articles/{slug}`)
- **逻辑调整**：查询条件由 `status = 1` 调整为 `status IN (1, 3) AND deleted = 0`。
- **效果**：
  - 任何人只要获取了链接 `/post/{slug}`，无论是否登录，均可正常打开并阅读完整正文；
  - 正常自增阅读计数 `view_count`。

### 2. 主页文章列表 (`GET /api/v1/articles`)
- **逻辑调整**：
  - 接口接收 `HttpServletRequest`，解析 `Authorization: Bearer <token>`；
  - 若包含有效的管理员 JWT Token，查询 `status IN (1, 3)`；
  - 若未携带 Token 或 Token 无效（普通访客），严格仅查询 `status = 1`；
  - `toPublicMap` 输出结果保留 `status` 字段供前台渲染。

### 3. 公开聚合与防泄露隔离
- **Sitemap (`SitemapController`)**：保持 `status = 1`，隐藏文章不进入站点地图；
- **RSS 订阅 (`RssController`)**：保持 `status = 1`，隐藏文章不进入 RSS feed；
- **公开归档 (`archives()`) / 标签聚合 (`tags()`)**：保持 `status = 1`，避免泄露隐藏文章。

### 4. 前端界面与交互 (Nuxt 3)
- **前台主页 (`pages/index.vue`)**：
  - 引入 `useAuth()` 登录态感知；
  - 管理员已登录状态下，调用列表接口时附带 Token；
  - 响应式监听 `isLoggedIn`（登录/登出时自动重载首页文章列表）；
  - 对 `status === 3` 的卡片，在标题旁展示 **`🔗 仅链接可见`** 专属徽章。
- **前台详情页 (`pages/post/[slug].vue`)**：
  - 针对 `status === 3` 的文章，自动注入防爬虫标签 `<meta name="robots" content="noindex, nofollow" />`；
  - 顶部展示轻量提示条：`🔗 仅链接可见（本文未在博客主页公开展示）`；
  - 点击“分享”按钮即可一键复制文章链接 `/post/{slug}`。
- **后台编辑页 (`pages/admin/edit.vue`)**：
  - 状态选择区域增加 **【仅链接可见】** 按钮（value: 3）；
  - 保存与发布支持 `status = 3`，首次保存时自动填充 `publishedAt`。
- **后台管理列表 (`pages/admin/posts.vue`)**：
  - 状态筛选支持 `status = 3`；
  - 文章列表状态徽章展示为“仅链接可见”（紫色/青色 Tag）。
