# 个人博客系统 (MyBlog) 阶段总结与演进路线图

> 本文档用于记录个人博客系统（基于 **Spring Boot 2.7 + Nuxt 3 SSG + SQLite 3.45**）截至 **v6.0-Final** 版本的阶段性架构总结及未来演进方向的 ROI 评估分析。

---

## 一、 项目阶段性成果与架构总结

个人博客系统已全面构建为一个**轻量高能、安全可控、易运维**的现代化个人博客平台。

### 1. 极致的资源控制与性能优化
- **Nuxt 3 SSG 全静态化**：前台公开页面全量采用静态预渲染，相比传统 SSR 服务省去 **150~250MB** 的 Node 进程内存开销。
- **SQLite 默认嵌入式存储**：支持 WAL 高并发模式（`journal_mode=WAL`），无需部署复杂的数据库服务，低配 **1C2G VPS** 亦可毫秒级流畅运行。

### 2. 企业级的安全性与合规审计
- **设备绑定防越权**：JWT 鉴权搭配管理者 `admin_device` 设备白名单，未授权设备拒绝访问敏感 API。
- **全局审计与链路追溯**：写操作全量持久化写入 `audit_log` 审计表；日志接入全链路 `X-Trace-Id` 串联。
- **全站 IP 限流与封禁**：应用层拦截高频 IP，自动挂载封禁名单（`ip_ban`），支持管理后台可视化手动解封。

### 3. 极简自动化的运维与防灾
- **AES-256 加密容灾备份**：一键加密打包全站 SQLite 数据库与上传附件，全自动推送到 GitHub 私有备份仓库，并支持进程级在线一键恢复。
- **Web UI 一键平滑升级**：基于后台 Python `upgrade-agent` 代理与 SSE 流式日志，实现基于 GitHub Release 的热部署及自动回滚。
- **开放的标准 RESTful 契约**：沉淀全量 **92 个 API 端点** 契约规范，业务逻辑与 UI 交互彻底解耦。

## 三、 未来演进方向评估排行榜 (按 ROI 从高到低排序)

结合个人博客应用场景、低配 VPS 运行痛点及开发 ROI，将 10 个演进方向按**价值/收益从高到低**评估重排如下：

### 🔴 第一梯队：P0 核心价值区 (投入小、见效快、直接影响留存与安全)

1. 🥇 **树状多级评论与邮件通知闭环 (排名 #1)**
   - **价值评估**：**【极高】** `comment.parent_id` 解决嵌套回复的上下文对齐，邮件通知解决跨时间的读者召回，构成完整的社区互动闭环。
2. 🥈 **富媒体图片 WebP 自动压缩 (排名 #2)**
   - **价值评估**：**【高】** 客户端或后端上传时自动转 WebP/AVIF，直接节约 50%~70% 的磁盘存储与服务器出站流量，大幅加快前台加载。
3. 🥉 **Actuator 监控与敏感接口隔离 (排名 #3)**
   - **价值评估**：**【高 (低成本避坑)】** 在 Nginx 或配置中加几行规则隔离敏感监控端点，投入近乎为零，防范安全泄露风险价值极大。

---

### 🟠 第二梯队：P1 关键运维与生产力区 (维持项目长期健康运行)

4. 🏅 **访问日志与 `page_view` 定时清洗 (排名 #4)**
   - **价值评估**：**【较高】** 定时清理膨胀的流量日志表，确保 SQLite 数据库体积始终维持在几十 MB 级，保证运行轻盈。
5. 🏅 **嵌入式全文检索 SQLite FTS5 (排名 #5)**
   - **价值评估**：**【较高】** 零增加独立服务，利用 SQLite 原生 `FTS5` 扩展实现文章正文的毫秒级全文匹配与检索高亮。
6. 🏅 **创作编辑器增强 (剪切板上传/Latex/Mermaid) (排名 #6)**
   - **价值评估**：**【较高】** 支持截图 Ctrl+V 自动落盘上传、Latex 数学公式与 Mermaid 图表渲染，直接提升日常写博客效率。

---

### 🟡 第三梯队：P2 扩展与高并发储备区 (视站点流量增长情况逐步落地)

7. 🎖️ **S3 / 阿里云 OSS / 腾讯云 COS 对象存储扩展 (排名 #7)**
   - **价值评估**：**【中等】** 抽象 `StorageService` 接口，在图片或附件达到几千张以上时解耦本地磁盘。
8. 🎖️ **二级缓存 (Caffeine 本地内存 / Redis) (排名 #8)**
   - **价值评估**：**【中等】** 对文章详情与热门标签组增加二级缓存，在日 PV 达到数万级高并发打压时发挥最大价值。

---

### 🔵 第四梯队：P3 生态与定制扩展区 (按个人兴趣或特定场景按需拓展)

9. 🎗️ **基于现有 92 个接口的多端扩展 (小程序/App) (排名 #9)**
   - **价值评估**：**【按需】** 利用解耦的 RESTful API 零成本衍生开发微信小程序端或 Flutter 移动客户端。
10. 🎗️ **全站多语言 (i18n) 国际化 (排名 #10)**
    - **价值评估**：**【按需】** 引入 `@nuxtjs/i18n` 为前台补充多语言切换，适合有海外读者或英文专栏的需求。
