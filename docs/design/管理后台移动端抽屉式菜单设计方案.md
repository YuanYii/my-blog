# 管理后台移动端适配设计方案
## 抽屉式侧边栏（Drawer Sidebar）

> 版本：v1.0 | 日期：2026-06-22 | 状态：待评审（2026-06-22）
> 对应 AGENTS.md 决策：前端全静态化（v2.7.0），admin 布局在 `layouts/admin.vue`

---

## 1. 现状分析

### 1.1 当前行为（≤768px）

`main.css` 的 `@media (max-width: 768px)` 中有：

```css
.admin-sidebar { display: none; }
```

→ 侧边栏完全隐藏，**没有替代导航手段**，移动端用户无法切换菜单。

### 1.2 现有布局结构

```
admin-layout          ← display: flex
  ├── aside.admin-sidebar   ← 240px, sticky, 当前在移动端被 display:none 干掉
  └── div.admin-main        ← flex:1
        ├── header.admin-header  ← sticky top:0, z-index:10
        └── main.admin-content
```

### 1.3 导航组数据（共 9 个菜单项）

| 分组 | 菜单项 | 有无 Badge |
|------|--------|-------------|
| 概览 | 仪表盘 | — |
| 内容 | 文章 | ✅ `meta.articleCount` |
| 内容 | 评论 | ✅ `meta.pendingComments` 红色 accent |
| 内容 | 分类 | — |
| 内容 | 标签 | — |

| 系统 | 站点设置 | — |

## 2. 设计目标

1. **≤768px**：侧边栏变为抽屉，点击汉堡按钮滑出，点击遮罩或按 Esc 关闭
2. **>768px**：保持现有行为不变（侧边栏常驻）
3. 复用现有 `.admin-sidebar` 的 DOM 结构和样式，改动最小化
4. 支持手势：右滑打开（可选，v2 再考虑）
5. 不影响 `admin-header` 右侧的主题切换/用户信息

---

## 3. 方案设计

### 3.1 响应式策略

| 断点 | 侧边栏行为 | 顶栏左侧 |
|-------|------------|----------|
| >768px（桌面） | 常驻显示，240px | 不显示汉堡按钮 |
| ≤768px（移动） | 默认隐藏（transform 移出） | 显示汉堡按钮 |

**断点选择理由**：当前 `main.css` 已有 `@media (max-width: 768px)` 规则块，保持一致性。

### 3.2 抽屉交互流程

```
用户点击汉堡按钮
  → sidebar 添加 .open（transform: translateX(0)）
  → 显示遮罩层 .drawer-overlay（opacity 过渡）
  → 禁止 body 滚动（overflow: hidden）

用户点击遮罩 / 按 Esc / 点击某个菜单项
  → sidebar 移除 .open
  → 隐藏遮罩层
  → 恢复 body 滚动
```

### 3.3 视觉规范

- **侧边栏本身**：完全复用现有 `.admin-sidebar` 样式（240px 宽、背景、导航项样式不变）
- **抽屉状态**：通过 `transform: translateX(-100%)` 隐藏，`translateX(0)` 显示
- **遮罩层**：`rgba(0,0,0,0.4)`，全屏 fixed，z-index 低于 sidebar 但高于主内容
- **过渡动画**：`transition: transform 0.25s ease, opacity 0.25s ease`
- **汉堡按钮**：在 `admin-header` 左侧，仅移动端显示（桌面端 `display: none`）

### 3.4 暗色模式兼容

侧边栏样式使用 CSS 变量（`var(--card)`, `var(--line)` 等），暗色模式已由 `html.dark` 统一处理，抽屉状态不需要额外适配。

## 4. 实现建议

### 4.1 改动范围

只需改 2 个文件，不新增文件：

| 文件 | 改什么 |
|------|--------|
| `layouts/admin.vue` | 加 `drawerOpen` 状态、`toggleDrawer`/`closeDrawer` 方法、汉堡按钮 DOM、遮罩层 DOM |
| `assets/css/main.css` | 把 `.admin-sidebar { display: none }` 改成 transform 动画 + 汉堡按钮样式 + 遮罩层样式 |

### 4.2 关键思路

**状态管理**（admin.vue）：
- `drawerOpen = ref(false)` 控制抽屉开关
- 打开时设 `document.body.style.overflow = 'hidden'` 防止背景滚动
- 关闭时恢复 `overflow = ''`
- 路由变化时自动关闭（`watch(route.path, closeDrawer)`）
- Esc 键关闭（`addEventListener('keydown', ...)`）

**DOM 结构**（admin.vue）：
- `<aside>` 加上 `:class="{ open: drawerOpen }"`
- `<header>` 最左侧插入汉堡按钮（SVG 三横线图标）
- `<aside>` 后面插入遮罩层 `<div class="drawer-overlay" v-if="drawerOpen" @click="closeDrawer">`

**CSS 动画**（main.css）：
- 桌面端（>768px）：侧边栏常驻，汉堡按钮 `display: none`
- 移动端（≤768px）：侧边栏 `position: fixed; transform: translateX(-100%)`，加 `.open` 时 `translateX(0)`
- 遮罩层：`position: fixed; inset: 0; background: rgba(0,0,0,0.4)`，用 `fadeIn` 动画
- 过渡：`transition: transform 0.25s ease`

### 4.3 注意事项

- 所有 `document`/`window` 操作包在 `if (import.meta.client)` 里，避免 SSR 报错
- 汉堡按钮默认 `display: none`，用 CSS 媒体查询在移动端覆盖为 `display: flex`
- `z-index`：遮罩层 190，侧边栏 200，确保侧边栏在遮罩上面
- 用 `100dvh` 代替 `100vh`，避免移动端浏览器工具栏遮挡

## 5. 边界情况处理

### 5.1 路由切换自动关闭

`watch(() => route.path, closeDrawer)` 确保移动端点击菜单项后抽屉自动收起。

### 5.2 窗口 resize 时重置状态

```ts
onMounted(() => {
  if (import.meta.client) {
    window.addEventListener('resize', () => {
      if (window.innerWidth > 768 && drawerOpen.value) {
        closeDrawer()
      }
    })
  }
})
```

### 5.3 服务器端渲染安全

所有 DOM 操作（`document.body.style.overflow`、`addEventListener`）都包在 `if (import.meta.client)` 中，避免 SSR 报错。

### 5.4 无障碍

- 汉堡按钮有 `aria-label="打开菜单"`
- 遮罩层可点击关闭，等同于"取消"操作
- Esc 键关闭抽屉

- [ ] 菜单项文字大小调整 → 保持现有 14px
