# 搜索引擎可搜索实现方案

> 2026-07-07 起草，域名 `https://blog.coreyai.cn/`，保持 `ssr: false`
> 方案：后端返回 HTML + 渐进增强（搜索引擎读静态内容，用户看到完整 Vue SPA）

---

## 1. 问题诊断

### 1.1 根因：`ssr: false` 导致预渲染 HTML 为空壳

当前配置 `ssr: false` + `nuxt generate`，预渲染产出的静态 HTML 实际是**空壳**：

```html
<!-- 搜索引擎看到的 -->
<html>
<head>
  <title>Loading...</title>
  <meta name="description" content="">
</head>
<body>
  <div id="__nuxt"></div>
  <script src="/_nuxt/app.js"></script>
</body>
</html>
```

搜索引擎爬虫不执行 JavaScript，看到的是空的 `<div id="__nuxt"></div>`，无法索引任何内容。

### 1.2 现有能力盘点

| 能力 | 状态 | 说明 |
|---|---|---|
| RSS Feed | ✅ 已有 | `/api/v1/rss`，后端 `RssController`，最近 20 篇 |
| robots.txt | ❌ 缺失 | 搜索引擎不知道可以爬 |
| sitemap.xml | ❌ 缺失 | 搜索引擎无法发现所有页面 |
| 文章页 meta | ❌ 缺失 | HTML 中无 title/description/og 标签 |
| 文章内容 | ❌ 缺失 | HTML 中无正文，搜索引擎无法索引 |

---

## 2. 方案：后端返回 HTML + 渐进增强

### 2.1 原理

后端返回的 HTML 页面**同时包含两层内容**：

1. **静态内容层**（`<div id="seo-content">`）：搜索引擎读这里
2. **Vue SPA 层**（`<div id="__nuxt">`）：用户看到这里

```
搜索引擎爬虫（不执行 JS）：
  看到 → #seo-content 中的静态文章内容 → 能索引 ✅

用户浏览器（执行 JS）：
  看到 → #seo-content 静态内容（瞬间可见，无白屏）
       → Vue SPA 加载后 → 替换为完整交互版
       → TOC 高亮、评论区、暗色模式等全部可用 ✅
```

### 2.2 渐进增强时序

```
用户打开 /post/pydantic-v2
  │
  ├─ 0ms     nginx → 后端返回 HTML
  │           浏览器渲染 #seo-content（静态文章内容，秒开）
  │
  ├─ 200ms   Vue SPA 开始加载（app.js）
  │
  ├─ 500ms   Vue SPA 加载完成
  │           ├─ 检测到 #seo-content 存在
  │           ├─ 隐藏 #seo-content（display:none）
  │           ├─ Vue 渲染完整页面到 #__nuxt
  │           ├─ TOC 侧边栏、评论区、暗色模式等交互功能恢复
  │           └─ 用户无感知切换
  │
  └─ 之后    正常使用交互功能
```

### 2.3 为什么选这个方案

| 对比维度 | 本方案（渐进增强） | 纯静态 HTML | 开启 SSR |
|---|---|---|---|
| 搜索引擎索引 | ✅ 全文 | ✅ 全文 | ✅ 全文 |
| 用户交互功能 | ✅ 完整（TOC/评论/暗色） | ❌ 无 | ✅ 完整 |
| 新文章生效 | **立即** | **立即** | 立即 |
| 是否需要 rebuild | **不需要** | 不需要 | 不需要 |
| 内存代价 | **无** | 无 | +200MB Node.js |
| 架构变更 | **小**（后端加接口 + nginx 路由） | 无 | 大 |

## 4. 详细设计

### 4.1 SeoController

**路由**：`GET /seo/post/{slug}`

**返回**：`text/html`，包含静态内容层 + Vue SPA 入口。

```java
@RestController
@RequestMapping("/seo")
@RequiredArgsConstructor
public class SeoController {

    private final ArticleService articleService;
    private final MarkdownRenderer markdownRenderer;

    @GetMapping(value = "/post/{slug}", produces = "text/html")
    public ResponseEntity<String> articlePage(@PathVariable String slug) {
        Article article = articleService.getBySlug(slug);
        if (article == null || article.getStatus() != 1) {
            return ResponseEntity.notFound().build();
        }

        String contentHtml = markdownRenderer.render(article.getContentMd());
        String html = buildHtmlPage(article, contentHtml, slug);

        return ResponseEntity.ok()
            .contentType(MediaType.TEXT_HTML)
            .header("Cache-Control", "public, max-age=3600")
            .body(html);
    }
}
```

**HTML 页面模板**（关键：同时包含静态内容和 SPA 入口）：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <title>{文章标题} | blog.coreyai.cn</title>
    <meta name="description" content="{文章摘要}">
    <meta property="og:title" content="{文章标题}">
    <meta property="og:description" content="{文章摘要}">
    <meta property="og:type" content="article">
    <meta property="og:url" content="https://blog.coreyai.cn/post/{slug}">
    <link rel="canonical" href="https://blog.coreyai.cn/post/{slug}">
    <style>
        /* 基础排版（静态内容用，Vue 加载后会被覆盖） */
        body { max-width: 720px; margin: 0 auto; padding: 20px; font-family: system-ui, sans-serif; line-height: 1.8; color: #333; }
        h1 { font-size: 1.8em; margin-bottom: 0.5em; }
        .summary { color: #666; font-size: 14px; margin-bottom: 2em; border-bottom: 1px solid #eee; padding-bottom: 1em; }
        pre { background: #f5f5f5; padding: 12px; border-radius: 4px; overflow-x: auto; }
        code { background: #f5f5f5; padding: 2px 4px; border-radius: 2px; }
        a { color: #e85d4a; }
        /* Vue 加载后隐藏静态内容 */
        .seo-hidden { display: none !important; }
    </style>
</head>
<body>
    <!-- ========== 层 1：静态内容（搜索引擎读这里） ========== -->
    <div id="seo-content">
        <h1>{文章标题}</h1>
        <div class="summary">{文章摘要}</div>
        <article>{文章正文 HTML}</article>
    </div>

    <!-- ========== 层 2：Vue SPA 挂载点（用户看到这里） ========== -->
    <div id="__nuxt"></div>

    <!-- ========== Vue SPA 脚本 ========== -->
    <script src="/_nuxt/app.js"></script>
</body>
</html>
```

### 4.2 MarkdownRenderer

使用 `flexmark-java`（Java 生态最成熟的 Markdown 库）。

```xml
<!-- backend/pom.xml 新增依赖 -->
<dependency>
    <groupId>com.vladsch.flexmark</groupId>
    <artifactId>flexmark-all</artifactId>
    <version>0.64.8</version>
</dependency>
```

```java
@Component
public class MarkdownRenderer {
    private final Parser parser;
    private final HtmlRenderer renderer;

    public MarkdownRenderer() {
        this.parser = Parser.builder().build();
        this.renderer = HtmlRenderer.builder().build();
    }

    public String render(String markdown) {
        if (markdown == null || markdown.isEmpty()) return "";
        Document document = parser.parse(markdown);
        return renderer.render(document);
    }
}
```

### 4.3 前端渐进增强兼容

修改 `frontend/pages/post/[slug].vue`，在 Vue 组件挂载时检测是否有静态内容，如有则隐藏。

```vue
<script setup>
// 现有逻辑不变：从 API 拉文章数据，用于交互功能（评论、TOC、相关文章）

// ========== 新增：渐进增强兼容 ==========
onMounted(() => {
  // 隐藏静态内容（SEO 层），显示 Vue SPA 渲染的内容
  const seoContent = document.getElementById('seo-content')
  if (seoContent) {
    seoContent.classList.add('seo-hidden')
  }
})
</script>
```

**用户体验**：
1. 页面打开瞬间看到静态文章内容（无白屏）
2. Vue SPA 加载后（~500ms），静态内容隐藏，交互功能出现
3. 过渡平滑，用户几乎无感知

### 4.4 nginx 配置

```nginx
# 文章页：转后端返回 HTML（含静态内容 + SPA 入口）
location /post/ {
    proxy_pass http://127.0.0.1:8080/seo/post/;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
    proxy_cache_valid 200 10m;
}

# 其他前端路由：仍走静态文件（Vue SPA）
location / {
    root /opt/myblog/frontend;
    try_files $uri $uri/ /index.html;
}

# API（不变）
location /api/ {
    proxy_pass http://127.0.0.1:8080;
}
```

## 8. 局限性

| 局限 | 影响 | 缓解 |
|---|---|---|
| 后端需新增 Markdown 渲染 | 增加 flexmark 依赖（~2MB） | flexmark 是纯 Java，无 native 依赖 |
| HTML 模板硬编码 | 修改排版需改 Java 代码 | 模板简单，后期可抽成配置或模板文件 |
| 静态内容与 SPA 排版可能有细微差异 | 过渡瞬间可能有闪烁 | 差异很小，且过渡很快（<500ms） |
