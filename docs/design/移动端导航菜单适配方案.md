# 移动端导航菜单适配方案

> 状态：待评审
> 作者：AI Assistant
> 日期：2026-06-22
> 对应 BUG：`BUG-NAV-MOBILE-001`

---

## 1. 问题描述

手机浏览器打开博客前台首页，顶部导航栏只显示：
- 左侧：站点 Logo + 标题
- 右侧：主题切换按钮

**「首页 / 归档 / 标签 / 关于」导航菜单完全不显示，用户无法切换页面。**

后台管理入口图标（`/admin/login`）在手机端也同样不可见。

---

## 2. 根本原因分析

| 文件 | 行号 | 代码片段 | 问题 |
|---|---|---|---|
| `components/NavBar.vue` | 17 | `class="hidden md:flex ..."` | `hidden` 在 `< 768px` 时隐藏，`md:flex` 仅在 `≥ 768px` 生效。手机端无替代菜单 |
| `components/NavBar.vue` | 29 | `class="hidden md:inline-flex ..."` | 后台管理入口图标同样被隐藏 |

**设计意图**：原作者显然打算后续补充移动端菜单，但只完成了桌面端，移动端留下空白。

---

## 3. 设计方案：汉堡菜单 + 下拉抽屉

### 3.1 设计概述

在手机端（`< 768px`）用「汉堡图标按钮」替代桌面端的水平导航菜单。点击汉堡按钮后，下拉展开垂直菜单列表；再次点击或点击菜单外区域，菜单收起。

### 3.2 交互流程（伪代码）

```
状态：isMenuOpen = false（菜单默认关闭）

--- 用户点击汉堡按钮 ---
onHamburgerClick():
  isMenuOpen = !isMenuOpen   // 切换菜单展开/收起状态

--- 用户点击菜单项 ---
onMenuItemClick(route):
  navigateTo(route)            // 跳转到目标页面
  isMenuOpen = false          // 自动关闭菜单

--- 用户点击菜单外区域 ---
onOutsideClick(event):
  if isMenuOpen and clickTarget not in menuArea:
    isMenuOpen = false        // 自动关闭菜单

--- 路由发生变化 ---
onRouteChange():
  isMenuOpen = false          // 路由切换后自动关闭菜单
```

```
│                                 │

```

### 3.4 桌面端兼容性

```
桌面端（≥ 768px）：
┌──────────────────────────────────────────────┐
│ [Logo] 首页 归档 标签 关于        🌓 👤    │
└──────────────────────────────────────────────┘

- 汉堡按钮：隐藏（md:hidden）
- 桌面菜单：显示（hidden md:flex）
- 下拉菜单：不渲染（md:hidden）
```

### 3.5 菜单项高亮逻辑（伪代码）

```
for each menuItem in menuList:
  if currentRoute == menuItem.route:
    addClass(menuItem, 'active-link')   // 高亮当前页
  else:
    removeClass(menuItem, 'active-link')
```

### 3.6 后台管理入口显示逻辑（伪代码）

```
if currentDevice in approvedDevices:
  show adminMenuItem                   // 已授权设备才显示后台入口
else:
  hide adminMenuItem
```

## 6. 风险提示

| 风险 | 影响 | 缓解措施 |
|---|---|---|
| 服务端渲染时报错 | 页面崩溃 | 确保菜单交互逻辑不在服务端执行 |
| z-index 堆叠冲突 | 下拉菜单被遮挡 | 确保菜单 z-index 高于页面内容 |
| 全静态化后路由监听失效 | 菜单不自动关闭 | 使用客户端路由监听，不依赖 SSR |
| 后台入口泄露（未授权设备可见） | 安全问题 | 保持设备授权验证逻辑不变 |
