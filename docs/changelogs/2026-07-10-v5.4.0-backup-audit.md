# v5.4.0 备份删除优化 + 审计记录去重 + 发布时间统一

> 版本：v5.4.0
> 日期：2026-07-10

---

## 变更摘要

### 1. 备份删除逻辑优化（fix）

- `BackupService.deleteBackupRecord` 移除 `deleteGitHubRelease` 调用
- 删除备份记录时仅删除本地 db 记录，GitHub Release 文件保留
- 用户可在 GitHub 手动管理备份文件，避免误删

### 2. 审计记录去重（fix）

- `AuditLogAspect` 跳过 `/admin/upgrade*` 路径，避免 aspect 自动记录 CREATE 与 UpgradeController 手动记录 UPGRADE 重复
- `audit-logs.vue` 补充 UPGRADE（升级）/ ROLLBACK（回滚）标签和配色

### 3. 发布时间统一展示（fix）

- 仪表盘"最近文章" + 文章列表：列头"更新时间"→"发布时间"
- 字段统一取 `publishedAt`，格式统一 `formatDateTime`（YYYY-MM-DD HH:mm）
- 仪表盘最近文章请求加 `sort=published_at:desc`

### 4. 分页组件增强（feat）

- 首页、备份列表、升级记录页增加每页条数选择和页码跳转
- 分页 CSS 样式优化（space-between 布局）

### 5. 版本号同步

- `backend/pom.xml` `<revision>` 5.3.0 → 5.4.0
- `scripts/deploy-server.sh` Usage 示例 + 头部注释同步更新
- `scripts/publish-release.sh` README 模板同步更新
