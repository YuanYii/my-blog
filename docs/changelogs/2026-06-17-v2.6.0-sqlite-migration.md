**两文件差异**：

| 项 | MySQL | SQLite |
|---|---|---|

| `INSERT IGNORE` | 同 | 改 `INSERT OR IGNORE` |
| seed data JSON | `JSON_OBJECT(...)` | JSON 字面量字符串 |

## 3. Java 代码改造

### 3.1 pom.xml

- 加 `org.xerial:sqlite-jdbc:3.45.0.0`（runtime scope）
- **保留** `com.mysql:mysql-connector-j`（profile 切回 MySQL 仍可用）

### 3.2 业务 SQL 跨方言（38 处）

**PageViewService**（4 处 MySQL 特有函数 + 1 处 IGNORE）：
- `CURDATE()` / `DATE_SUB(CURDATE(), INTERVAL ? DAY)` / `NOW()` / `DATE_SUB(NOW(), INTERVAL 30 DAY)`
- → Java 端传 `LocalDate.now()` / `LocalDate.now().minusDays(days)` / `LocalDateTime.now().minusDays(30)`
- INSERT IGNORE → **业务层 selectCount 判断去重**（v2.6.0-fix：因 MyBatis-Plus BaseMapper.insert 在 SQLite 下因 `getGeneratedKeys()` 失败导致异常被吞，改用 `JdbcTemplate.update`）

**DashboardController**（1 处 MySQL 函数）：
- `DATE_SUB(NOW(), INTERVAL 30 DAY)` → Java 端传 `LocalDateTime.now().minusDays(30)`

**ArticleController**（2 处 INSERT IGNORE）：
- 改为业务层 `insertArticleTagIfNotExists`（SELECT COUNT + INSERT 两步）

**PageViewMapper**（去掉方言特定 SQL）：
- `@Insert("INSERT IGNORE INTO ...")` 注解删掉，走 `JdbcTemplate.update` 通用路径

### 3.3 实体 / 主键策略

- 7 个 entity 的 `@TableId(type = IdType.AUTO)` **不动**——MyBatis-Plus 3.4.3.4 `IdType.AUTO` 自动适配 MySQL / SQLite
- page_view 实体加 `visitDate: LocalDate` 字段

### 3.4 PageViewFilter（日志级别）

- catch 块改 `log.warn`（带 stacktrace），`log.debug` 只在业务层去重命中时输出
- 加注释：Hikari 单连接 + SQLite 单写者锁 → `maximum-pool-size: 1` 必须

## 4. 配置调整（4 个 profile 矩阵）

### application-dev.yml（默认 SQLite）
```yaml
spring:
  datasource:
    driver-class-name: org.sqlite.JDBC
    url: jdbc:sqlite:${SQLITE_PATH:${user.dir}/../blog.db}  # 注意 ../ 避免 spring-boot:run 解析到 blog-app/
    hikari:
      maximum-pool-size: 1   # SQLite 单写者锁
```

### application-prod.yml（默认 SQLite，1C2G 调参）
```yaml
spring:
  datasource:
    url: jdbc:sqlite:${SQLITE_PATH:/data/blog.db}
    hikari:
      maximum-pool-size: 1
server:
  tomcat:
    max-threads: 50  # 1C2G 从 100 调小
```

### application-mysql.yml（可选 profile 片段）
- 切回 MySQL 用：`spring.profiles.active=dev,mysql`
- 只覆盖 datasource，其他配置保持

## 5. 数据迁移（MySQL → SQLite）

**两个实现**（先 sed 版踩坑后改 pymysql 直连版）：

### 最终版本：migrate-mysql-to-sqlite-direct.py
- 用 `pymysql` 直连 MySQL 读所有行
- 用 `sqlite3` Python 模块直写 SQLite
- `INSERT OR REPLACE` 避免主键冲突
- 11 张表全部迁移成功，**123/123 行导入**（含 article 的 markdown 内容含 `\'`、`反引号`、emoji 等特殊字符）

### 踩过的坑（备忘）
1. **mysqldump 反引号**：反引号要删，macOS sed `s/\`//g` 在 zsh 里要换 `tr -d '`'`
2. **mysqldump 无引号值**：MySQL 对无歧义值（`2026-06-13 15:42:13`）不输出引号，SQLite 解析报错
3. **mysqldump 反斜杠**：内容里的 `\` 是字面字符，SQLite 不识别 → 难做字符串字面量级修复
4. **SQLite 客户端 .read 怪行为**：多行 INSERT 被拼一起 → 用 Python `cursor.execute` 逐条
5. **schema 字段不对齐**：`comment` 表漏 `parent_id` / `website` 字段；`category` 字段名 `sort` vs `sort_order`（MyBatis-Plus `map-underscore-to-camel-case` 反推）

### 关键设计
- **先清空目标表**（schema 的 seed data 跟 MySQL id 冲突会重复）
- **password_hash 用真实值**（不是默认占位）——首次部署即可登录

## 7. 生产部署脚本

**`scripts/deploy-sqlite.sh`**：洛杉矶 1C2G Ubuntu 适用

**流程**：
1. 权限检查（需 root）
2. 系统依赖检查（java / redis-server / sqlite3）
3. 创建 `myblog` 系统用户（无登录 shell）
4. 建 `/opt/myblog/{logs,backups,uploads}` 目录结构
5. 检查 `blog-app.jar` 是否在 `/opt/myblog/`
6. **首次部署**：用 `schema-sqlite.sql` 初始化 `/opt/myblog/blog.db`
7. 启动 redis（systemd）
8. 创建 systemd service（`/etc/systemd/system/myblog.service`）
   - **安全加固**：`NoNewPrivileges` / `PrivateTmp` / `ProtectSystem=strict` / `ProtectHome`
   - **JVM**：`JAVA_OPTS=-Xms128m -Xmx256m -XX:+UseG1GC`（1C2G 极限）
   - **Restart=on-failure** + **RestartSec=10**
9. 重启服务 + 30 秒健康检查轮询
10. 输出运维命令清单

**切换 MySQL**：等后续 deploy-mysql.sh 完善（用户明确推迟）。

## 9. 风险点 & 后续 backlog

| 风险 / 后续 | 说明 | 优先级 |
|---|---|---|
| SQLite 单写者锁 | 当前 Hikari `maximum-pool-size: 1`，5 个并发请求会排队 | 🟡 中 |
| 公开页统计并发 | PageViewFilter 在 5 并发下会阻塞（实测 5 次 /articles 5 秒） | 🟡 中 |
| `Updates: 1` 假象 | MyBatis-Plus BaseMapper.insert + SQLite getGeneratedKeys 失败时返回 1 但数据未落库（已规避：改用 JdbcTemplate.update） | 🟢 低 |
| article 数量 > 1000 | dashboard `computeTotalWordCount` 全表扫描会变慢 | 🟡 中 |
| `page_view` 无分区 | 长期数据会很多；按月清理脚本待加 | 🟡 中 |
| deploy-mysql.sh | 5 容器 docker-compose 方案（用户明确推迟） | 🟢 低 |
| GitHub Actions CI/CD | 自动化测试 + 镜像推送（待后续） | 🟢 低 |
| article.word_count 字段 | 写时计算 + 增量更新（避免 dashboard 全表扫描） | 🟡 中 |
| 访客 cookie 强制下发 | PageViewFilter `Set-Cookie: blog_visitor_id` 给无 X-Visitor-Id 的访客（彻底解决 curl/反爬漏统计） | 🟢 低 |
