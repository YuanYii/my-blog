# 2026-08-05 v6.0.0–v6.0.2 — 文章置顶 + 增量升级 + 多特性 sprint

> 版本号从 v5.4.2 升至 v6.0.2。本轮为密集 sprint（约 30 个 commit），覆盖 7 大功能块：文章置顶、增量升级脚本 upgade.sql、系统升级失败详情、模拟日志、近 3 天浏览数、Prometheus 监控、前台分类页、访客 IP 归属地、autodev flow v2 引擎升级 + Hermes-Evolution 指导、README 重构。

## TL;DR

- **文章置顶**：`article.is_pinned` 字段 + 后端排序置顶优先 + 前端首页/管理后台置顶徽章（⭐"置顶"替换原"最新"）
- **增量升级脚本**：`docs/sql/upgrade.sql` 统一管理所有增量 DDL，`deploy-server.sh` 执行时逐条 PRAGMA 检查（幂等可重复跑）
- **升级失败详情**：`upgrade-agent.py` 失败时截取最后 50 行日志写入 `error_message`，前端 FAILED 状态可点击查看完整失败信息
- **模拟服务报错日志**：后端 `POST /admin/settings/simulate-log` + 前端 `LogSimulatorDialog.vue`，站点设置「启用缓存」连续点击 5 次触发弹窗（3 秒超时重置）
- **近 3 天新增浏览数**：管理后台文章列表「浏览」列展示 `总浏览（+近3天新增）`，+N 绿色高亮，新增为 0 时隐藏
- **Prometheus 监控**：`micrometer-registry-prometheus` 依赖 + `/actuator/prometheus` 端点 + HTTP 请求百分位直方图/SLA 分桶
- **前台分类页**：`/categories` 公开页（分类云 + 选中下拉文章 + 带参分页 + 跳转），后端分类列表附带 `articleCount`（仅已发布）
- **访客 IP 归属地**：`IpLocationUtil` 内网识别 + 预置规则匹配公网 IP + LRU 缓存（1024 上限），仪表盘「访客 IP 来源」卡片展示 IP【归属地】
- **autodev flow v2**：全新的 `autodev/skills/autodev-flow/` 引擎（7 个 LLM agent 角色 + 2 个 workflow + `graph_runner.py` 编排），替换旧 `autodev/` 目录
- **Hermes-Evolution 指导**：`AGENTS.md` 末尾追加 OpenClaw Hermes-Evolution 区块（evolution 强度、核心原则、Evolution Echo 规则）
- **README 重构精简**：从 920 行压缩到 ~290 行（删 775 行冗余历史描述，保留核心栈/快速开始/部署/版本记录）

## 三、系统升级失败详情查看 (BUG-001)

**commit** `980d0df`

**现象**：升级历史 FAILED 状态仅显示截断 30 字 error-reason 且不可点击，与数据恢复页弹框体验不一致。

**根因**：`upgrade-agent.py` 失败时 `error_msg` 写死「升级失败」，完整日志仅存于 agent 内存不落库。

**修复**：
- `scripts/upgrade-agent.py`：新增 `build_failure_message()`，失败时从 `state.logs` 截取最后 50 行写入 `error_message`（替代空壳文案）
- `frontend/pages/admin/upgrade.vue`：照搬 `restore.vue` 失败详情弹框，FAILED 且含 `errorMessage` 时状态 badge 可点击展示完整失败信息

## 九、访客 IP 归属地展示 (IpLocationUtil)

**commit** `1c4690e`

### 9.1 IpLocationUtil

**新建** `backend/blog-common/src/main/java/com/blog/common/util/IpLocationUtil.java`（117 行）：
- `isInternalIp()`：识别 127.0.0.1 / ::1 / 10.x / 172.16-31.x / 192.168.x / localhost → "内网IP"
- `getLocation(ip)`：公网 IP 走预置规则匹配（114.114.114.x→江苏南京、223.5.5.x→浙江杭州、180.76.76.x→北京、119.29.x/182.254.x→广东深圳、8.8.8.x→美国、1.1.1.1→澳大利亚），默认"未知"
- LRU 缓存：`ConcurrentHashMap(256)` 上限 1024，防止重复解析
- `getDisplayIp(ip)`：格式化输出 `IP【归属地】`，例如 `114.114.114.114【江苏南京】`
- 附带单元测试 `IpLocationUtilTest.java`

### 9.2 仪表盘集成

- `PageViewService.topVisitorIps()` 和 `topVisitorIps30d()`：返回数据追加 `location` 和 `displayIp` 字段
- `frontend/pages/admin/dashboard.vue`：「访客 IP 来源」卡片渲染由 `s.ip` 改为 `s.displayIp`（带归属地标注）

### 9.3 autodev 契约产物
