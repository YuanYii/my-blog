# 2026-08-20 v7.0.0 仅链接可见文章 (Unlisted Post) 全链路支持与权限隔离

## 一、背景与目标

为满足私密分享、小范围传阅与特定受众文章发布需求，博客系统引入「仅链接可见文章 (Unlisted Post, `status = 3`)」功能：
1. **未登录普通访客**：访问首页或公开接口，列表完全隐藏该文章。
2. **管理员登录态**：访问首页可直接浏览该文章，并在卡片标题旁标有专属 **`🔗 仅链接可见`** 徽章。
3. **直达阅读**：任何人只要获取文章链接 `/post/{slug}`，均可直接打开并阅读完整正文。
4. **防搜索引擎泄露**：Sitemap (`sitemap.xml`)、SEO 控制器 (`/seo/post/{slug}`)、RSS、公开归档 (`/archives`) 严格隔离排除；文章详情页针对 `status = 3` 自动注入 `<meta name="robots" content="noindex, nofollow" />`。
5. **全流程管理闭环**：管理后台编辑页 (`edit.vue`) 与文章列表 (`posts.vue`) 全面支持该状态的选择、保存、筛选与徽章展示。

## 二、变更内容

### 1. 后端鉴权与业务逻辑
- **`AdminAuthFilter.java`**：公开 GET 请求增加可选鉴权尝试 (`tryOptionalAuth`)，携带有效 Bearer Token 时解析并将管理员身份注入 `AuthContext`。
- **`Article.java`**：实体类补充 `status: 3-仅链接可见` 状态声明。
- **`ArticleController.java` & `ArticleService.java`**：
  - `list()`：动态判断操作人身份，管理员查询 `status IN (1, 3)`，普通访客严格查询 `status = 1`。
  - `detail(slug)`：查询条件放宽为 `status IN (1, 3)`，允许直接通过链接匿名阅读正文。
  - `create()` / `update()`：`status` 校验支持取值 `3`，首次保存自动填充 `publishedAt`。
  - `toPublicMap`：输出项包含 `status` 字段，供前台动态判断与渲染。

### 2. 前端界面与防爬虫标签
- **`usePublicApi.ts`**：`get()` 方法支持透传自定义 headers/options。
- **`index.vue`**：集成 `useAuth()` 登录态，管理员登录态下请求列表携带 Token，对 `a.status === 3` 卡片渲染 `🔗 仅链接可见` 专属徽章。
- **`post/[slug].vue`**：使用 `useHead` 为 `status === 3` 文章动态注入 `<meta name="robots" content="noindex, nofollow" />`，并在文章正文上方展示紫色提示条。
- **`admin/edit.vue`**：状态选择区域增加「仅链接」选项（value: 3），保存与分类校验适配。
- **`admin/posts.vue`**：增加 `3: '仅链接'` 状态徽章映射（`badge-purple`）与下拉筛选。
- **`main.css`**：新增 `.unlisted-badge` 与 `.badge-purple` 样式。
