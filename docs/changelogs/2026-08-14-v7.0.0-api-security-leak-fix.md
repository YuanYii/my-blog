# 2026-08-14 v7.0.0 公开接口信息泄露防御、后台路由规范化与封面图自适应渲染

## 一、背景与问题

安全审计与体验走查中发现多处公开接口字段泄露、鉴权边界及前端封面图渲染缺失问题：
1. **草稿附件越权下载（P0）**：`GET /articles/{id}/attachment` 未联动校验所属文章状态，草稿及软删文章附件可被遍历枚举下载。
2. **公开文章接口字段泄露与正文膨胀（P1）**：`GET /articles` 与 `GET /articles/archives` 返回了全量 Markdown 正文（`contentMd`）及敏感审计时间戳（`createdAt`, `updatedAt`, `status`）。
3. **后台编辑端点混淆（P2）**：`GET /articles/id/{id}` 未使用 `/admin/` 前缀，存在路由层混淆风险。
4. **公开评论状态冗余（P3）**：`GET /comments` 冗余输出 `status: 1` 内部枚举状态。
5. **文章封面图未渲染（P2）**：文章上传/配置封面图后，首页列表与文章详情页未渲染封面图 DOM。

---

## 二、变更内容

### 1. 后端安全加固与字段重构
- **`AttachmentService.java`**：在 `resolveFile` 增加关联文章发布状态（`status = 1 AND deleted = 0`）校验，草稿或软删文章统一返回 404。
- **`ArticleService.java`**：引入 `toPublicMap` 白名单投影方法，彻底从公开列表与归档接口剔除 `contentMd`、`createdAt`、`updatedAt`、`status`；公开详情保留 `contentMd` 但剔除内部审计字段。
- **`ArticleController.java` & `AdminAuthFilter.java`**：将 `GET /articles/id/{id}` 统一迁移为 `GET /articles/admin/detail/{id}`，天然纳入 `/articles/admin/` 鉴权保护。
- **`CommentService.java`**：公开评论列表 SQL 剔除 `c.status` 投影列。

### 2. 前端页面、样式与 SSG 构建适配
- **`fetch-routes.js`**：移除对 `r.status === 1` 的硬依赖，基于 `r.slug` 抓取预渲染路由。
- **公开页面解耦**：`index.vue`、`archives.vue`、`categories.vue`、`tags.vue`、`search.vue`、`post/[slug].vue` 解耦 `a.createdAt`，统一基于 `a.publishedAt` 进行时间格式化展示。
- **管理后台适配**：`edit.vue` 与 `attachments.vue` 路径升级为 `/articles/admin/detail/${id}`。
- **封面图自适应渲染**：
  - `index.vue`：文章卡片支持双栏图文布局（带封面图时左文右图、移动端上下堆叠；无封面图时自动全宽纯文字回退）。
  - `main.css`：新增 `.post-card-inner`、`.post-card-thumb`（16:9/4:3 比例、悬停微缩放）、`.post-hero-cover` 及移动端 `@media (max-width: 640px)` 断点。
  - `post/[slug].vue`：在正文顶部增加封面大图 Banner 渲染，配置 `loading="lazy"` 与 `decoding="async"`。
