# v5.4.2 — 修复 universal-script.sh 部署缺失

## 背景

`universal-script.sh`（通用数据刷数脚本）在 `publish-release.sh` 中已打包到 release assets，但 `deploy-server.sh` 在**没有冷部署包**的分支（else 分支）漏掉了该脚本的下载，导致生产环境部署后 `/opt/myblog/scripts/universal-script.sh` 不存在。

## 改动

- `scripts/deploy-server.sh`：在 else 分支（单独下载文件时）新增 `download "universal-script.sh"`

## 版本号变更

- `<revision>` 5.4.0 → 5.4.2
- deploy-server.sh 注释/错误提示中的版本号同步更新
- publish-release.sh README 模板中的版本号同步更新

## 升级说明

- 纯脚本修复，无数据库变更
- 下次部署时 deploy-server.sh 会自动下载 universal-script.sh 到 `/opt/myblog/scripts/`
- 无需手动操作
