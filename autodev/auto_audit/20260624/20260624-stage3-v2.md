## 🟡 警告

### WARN-001：ArticleImportService.importOneArticle 单方法 100+ 行偏长
- **文件**：`backend/blog-article/src/main/java/com/blog/article/service/ArticleImportService.java`，第 248-352 行
- **维度**：规范
- **描述**：`importOneArticle` 单方法 100+ 行，串联了 5 个职责（标题/slug 生成 → 图片提取上传 → front matter 解析 → article 入库 → 标签关联）。按 AGENTS.md Java 方法长度 > 80 行警告阈值，建议拆分。
- **修复建议**：可下沉为 `resolveTitleSlug` / `processImages` / `applyFrontMatter` 3 个 private 方法（不影响功能，仅可读性）。本期任务限定不重构，留待下次清理。

### WARN-002：findOrCreateCategory / findOrCreateTag 存在 TOCTOU 竞态
- **文件**：`backend/blog-article/src/main/java/com/blog/article/service/ArticleImportService.java`，第 358-388 行
- **维度**：性能/并发
- **描述**：`findOrCreate` 先 SELECT 再 INSERT,两个导入任务（虽然 articleImportExecutor 是单线程,但 admin 多 tab 创建分类/手动调 API 同时进行时仍可能并发）撞同名时第二次 INSERT 会触发 slug unique 约束抛异常,虽然代码用了 "+ System.currentTimeMillis()" 兜底,但在极端情况下两个请求拿到的 currentTimeMillis 也可能相同。
- **修复建议**：影响范围低（articleImportExecutor 单线程串行,跨任务源极少触发）。可后续改成 INSERT + catch DataIntegrityViolation 重新 SELECT 取已存在记录。本期暂不阻塞。

## 🟢 建议

### SUG-001：MarkdownImporter.toStringList 用 Arrays.asList 包装单值兼容性 OK,但语义稍隐
- **文件**：`backend/blog-article/src/main/java/com/blog/article/util/MarkdownImporter.java`，第 228-237 行
- **描述**：`toStringList` 在 front matter 写 `tags: Java` （非 list 形式）时退化为单元素列表是合理的——但用 `Arrays.asList` 包装后又用 ArrayList 包一层稍冗余。可直接 `new ArrayList<>(Collections.singletonList(s))` 表达意图。属代码风格,不影响功能。

### SUG-002：RestoreStartupReconciler 孤儿扫描每次重做的开销
- **文件**：`backend/blog-settings/src/main/java/com/blog/settings/config/RestoreStartupReconciler.java`，第 158-200 行
- **描述**：`reconcileOrphanResults` 每 5 分钟全量列出 RESTORE_RESULT_DIR 下所有 `.json` 文件并 existsById 查 DB。当 result_dir 文件累积到 100+ 时,每轮会做 100 次 SQL count。建议给已重建过的 id 加进程内缓存（Set<Long>）跳过,或者在重建成功后给 .result.json 改名加 `.processed` 后缀（运维可见）。当前个人博客规模可忽略,留作后续优化。

### SUG-003：ArticleImportDialog.vue 上传 + 轮询 + 历史展示三块逻辑较密
- **文件**：`frontend/components/admin/ArticleImportDialog.vue`，全文
- **描述**：组件 200 行 + style,包含文件选择/校验/上传/轮询/模板下载/历史五块逻辑。可拆出 `useArticleImport.ts` composable（原任务设计中已规划但本期合并未拆）。当前文件长度未超组件 300 行警告阈值,可不拆。
