## 🟡 警告

### WARN-001：CommentService 评论限流仍是 IP 维度可被刷爆
- **文件**：`backend/blog-comment/src/main/java/com/blog/comment/service/CommentService.java`，第 168-183 行
- **维度**：安全
- **描述**：本轮新增 `enableCommentModeration=false` 分支会让评论直接公开（status=1）。如果同时审核开关关闭 + 限流绕过（代理换 IP），将形成放大攻击通路。当前固定窗口限流（10/分钟）已经有，但本轮未做强化。
- **修复建议**：审核关闭场景下叠加内容反垃圾（长度上限已有，可加敏感词 / 链接数阈值），或在 README 中明示"关闭审核仅适用于受信场景"

### WARN-002：RssController 缺少缓存与速率限制
- **文件**：`backend/blog-app/src/main/java/com/blog/controller/RssController.java`，第 60-93 行
- **维度**：性能
- **描述**：每次 `GET /rss[.xml]` 都触发 `articleService.list(1, 20, ...)`（含 selectPage + fillTagIds + tag/article_tag 关联查询）。爬虫频繁拉取时 DB QPS 上升。
- **修复建议**：把 RSS XML 缓存到 Redis（TTL 5 min），更新文章时主动清；或将 RSS 用 nitro 静态预渲染。

### WARN-003：useSiteTheme 在 SSR 阶段无法注入 CSS 变量，依赖 client mount 才能生效
- **文件**：`frontend/composables/useSiteTheme.ts`，第 41-72 行
- **维度**：性能 / UX
- **描述**：`applyTheme()` 仅在 `import.meta.client` 阶段调用；SSR 输出的 HTML 不带运行时主题色，初次 paint 走 `:root` 默认值（`#2f6f5e`），客户端 mount 后再切到用户自定义颜色——会出现可见的颜色"跳变"。
- **修复建议**：把 primaryColor/accentColor 缓存到 cookie，配合 `useHead.script` 注入内联同步脚本（参考 app.vue 现有 dark class 预注入模式）。本轮 DEV-001 验证清单已经标记 [🔍] 作为待运行确认项，不阻塞合并。

## 🟢 建议

### SUG-001：useSiteTheme 与 useSitePreferences 都对 `import.meta.client` 做了双重判断
- **文件**：`frontend/composables/useSiteTheme.ts`、`frontend/composables/useSitePreferences.ts`
- **描述**：watch immediate 回调与 onMounted 都会调 apply 一次。client 端会调两次（一次 watch immediate，一次 onMounted），无功能影响但 onMounted 中的调用是冗余。

### SUG-002：RssController 字符转义实现过于朴素
- **文件**：`backend/blog-app/src/main/java/com/blog/controller/RssController.java`，第 104-108 行
- **描述**：手写 `xmlEscape` 顺序很重要（先 `&`），目前正确，但用 `org.apache.commons.text.StringEscapeUtils.escapeXml11` 更稳，或换 ROME RSS 库。

### SUG-003：AdvancedSettingsAccessor 缓存失效未由 SiteSettingsService.put() 触发
- **文件**：`backend/blog-settings/src/main/java/com/blog/settings/service/AdvancedSettingsAccessor.java`
- **描述**：30s TTL 已足够，但当 admin 改 advanced 时 SiteSettingsService.put() 已 evict Redis，可顺手调 `accessor.invalidate()`，让 advanced 设置改完立即生效（不必等 30s）。

### SUG-004：useI18n 字典是静态 import 而非懒加载
- **文件**：`frontend/composables/useI18n.ts`，第 13-16 行
- **描述**：当前 2 个字典都进首包；语言增多时建议改 `import('~/i18n/{lang}.json')` 动态 import。本轮 2 个语言×十多个 key 影响可忽略。
