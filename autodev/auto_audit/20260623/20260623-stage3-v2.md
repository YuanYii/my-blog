## 🟡 警告

### WARN-001：settings 9 个子页存在大量重复样板代码（load + save + message + button）
- **文件**：`frontend/pages/admin/settings/{blog,techstack,experience,theme,social,preferences,advanced}.vue`，每文件 ~46 行
- **维度**：规范（重复代码）
- **描述**：7 个子页的 script setup 几乎是同构的 `load()` + `save()` + `saving/message` 逻辑，模板尾部「保存按钮 + message 提示」也完全一致；同样代码片段重复出现 ≥ 7 次，违反 DRY 原则
- **修复建议**：抽取一个 `composables/useAdminSettingsTab.ts`（接受 endpoint + initial + onSaved 回调）封装 load/save/saving/message；模板侧抽取一个 `<AdminSettingsSaveBar :saving :message @save="save" />` 组件复用按钮 + 提示行。本轮任务卡片明确"原 9 个 Form 组件零改动"，未要求新建 composable/组件，可在下一轮迭代再做抽离

### WARN-002：layouts/admin.vue 文件长度 365 行，已超出 Vue SFC > 300 行警告阈值
- **文件**：`frontend/layouts/admin.vue`，第 1-365 行
- **维度**：规范（文件长度）
- **描述**：本轮新增二级菜单 children 渲染与展开/折叠逻辑后，文件从约 280 行膨胀到 365 行；模板中导航 icon SVG（dashboard/file/message/folder/tag/device/backup/restore/settings）内联了 ~80 行 SVG path
- **修复建议**：将 SVG 图标按 `icon` 字符串映射抽出为 `<AdminNavIcon :name="item.icon" />` 子组件，模板侧可省 ~80 行；可在下一轮迭代实施

### SUG-001：dashboard 表格 `.recent-views-inline::before` 内容 ` · ` 含尾随空格
