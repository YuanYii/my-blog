## 🟡 警告

### WARN-001：UpgradeController 线程池未关闭
- **文件**：`backend/blog-app/src/main/java/com/blog/upgrade/UpgradeController.java`，第 39 行
- **维度**：性能
- **描述**：`Executors.newCachedThreadPool()` 创建的线程池没有 `@PreDestroy` 关闭逻辑，应用关闭时线程池中的线程可能泄漏。
- **修复建议**：添加 `@PreDestroy` 方法调用 `sseExecutor.shutdownNow()`，或将线程池改为 Spring 管理的 Bean（`@Bean` + `@PreDestroy`）。

### WARN-002：UpgradeController 手动拼接 JSON 字符串
- **文件**：`backend/blog-app/src/main/java/com/blog/upgrade/UpgradeController.java`，第 93-95 行
- **维度**：安全
- **描述**：用 `String.format` 手动拼接 JSON 请求体，若 `version` 或 `confirm` 包含双引号/反斜杠等特殊字符，会产生非法 JSON。虽然当前输入来自前端可信来源，但不符合防御性编程原则。
- **修复建议**：使用 Jackson `ObjectMapper` 序列化 Map 或 POJO，与项目已有风格一致（`UpgradeService` 中已用 `ObjectMapper`）。

### WARN-003：UpgradeService 每次调用创建新 ObjectMapper
- **文件**：`backend/blog-app/src/main/java/com/blog/upgrade/UpgradeService.java`，第 158 行、第 173 行
- **维度**：性能
- **描述**：`parseJsonMap` 和 `parseJsonReleaseList` 每次调用都 `new ObjectMapper()`。ObjectMapper 是线程安全的，应复用为 static final 字段。
- **修复建议**：提取为 `private static final ObjectMapper MAPPER = new ObjectMapper();`。
