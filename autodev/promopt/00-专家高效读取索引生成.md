文档说明：
    将用户指定的文档转化为面向 LLM 的高效读取格式

**读者是大模型，不是人**

目标：
1. **无损**：事实、约束、数字、专有名词、关系全保留
2. **最简**：去散文化、去 emoji、去客套、去重复；散文段转结构
3. **结构化自选**：YAML / JSON / 键值对 / 缩进 / 符号 DSL 均可
4. **显式关系**：依赖、优先级、类型、约束用键名或符号标出
5. **允许压缩**：常见术语首次定义后可用短名/缩写

硬约束：
- 信息无损是底线，宁少压不丢
- 第一行注明使用的格式（如 `# format: yaml-compact`）
- 直接输出转写结果，不要解释、不要前言后语
- 自检一遍：原文每条事实是否都能在你输出里检索到？

生成路径：
- 与原文档同路径

生成格式：
- LLM-【原文件名】.md
