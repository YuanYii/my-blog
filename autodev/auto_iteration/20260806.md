## BUG项

### 20260806-BUG-001 仪表盘访问趋势图隔天日期与访客数据错位修复

- **优先级**：高
- **状态**：✅ 已完成
- **解决时间**：2026-08-06 08:06:00
- **涉及文件列表**：
  - `frontend/composables/useDashboardUtils.ts`
- **根因分析与描述**：
  - `TrafficChart.vue` 中的 X 轴标签使用浏览器的本地时区（`getMonth() + 1` / `getDate()`）生成（如 `8/6`）。
  - `useDashboardUtils.ts` 中的 `fillDays` 函数在从 `map` 提取数值时，调用 `d.toISOString().substring(0, 10)`，使用的是 **UTC 零时区**日期。
  - 当在东八区（UTC+8）凌晨 00:00 ~ 07:59 打开页面时，`d.toISOString()` 输出的时间转换为 UTC 仍属于前一日（`2026-08-05T23:33:28.000Z`），截出的 Key 为 `"2026-08-05"`，导致查出昨日访客数据填入当天的图例位置，整条折线数据错位 1 天。
- **修复方案**：
  - 在 `frontend/composables/useDashboardUtils.ts` 中新增按本地时间格式化 `YYYY-MM-DD` 的 helper 函数 `toLocalDateString(d: Date)`。
  - 在 `fillDays` 匹配键逻辑中使用 `toLocalDateString` 替换原 `d.toISOString().substring(0, 10)`，保证匹配 Key 的年月日与本地图例标签完全一致。
- **验证清单**：
  - [x] 本地时区跨天/凌晨测试，确认折线图 X 轴当天标签与获取到的当天 PV/UV 访问统计完全吻合。
  - [x] 校验 `dashboard.vue` 顶栏 sparkline 趋势图是否同步正常渲染。
