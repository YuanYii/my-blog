### 20260801-DEV-001 | 中 | ✅ 已完成

- **开发内容**：
  管理后台文章列表（frontend/pages/admin/posts.vue）"浏览"列，展示
  【总浏览次数（+近3天新增）】，+N 用绿色高亮。例：总浏览 50、近3天
  新增 10 → 显示 50（+10），"+10" 为绿色。

  1. 后端 GET /articles/admin/all 每条记录新增 viewCount3d 字段：
     统计该 article_id 在 page_view 表中近 3 天（visit_date >= 今天-2天，
     含今天）的 COUNT(*)，无记录为 0
  2. 前端 posts.vue 浏览列渲染为 50（+10），+N 绿色（如 var(--success)）；
     **近3天新增为 0 时隐藏 +N，仅显示总浏览次数**

- **开发建议**：
  - 后端复用 fillAttachmentCounts 批量模式（一条 SELECT article_id, COUNT(*)
    FROM page_view WHERE article_id IN (...) AND visit_date >= ? GROUP BY article_id），
    JdbcTemplate + LocalDate 传参，跨方言（与 dailyStats/topArticles 一致）
  - "近3天"语义 = visit_date >= LocalDate.now().minusDays(2)，与项目
    "近N天=minusDays(N-1)含今天"惯例对齐
  - 前端绿色样式用现有 CSS 变量，无 --success 则内联颜色
  - +0 时隐藏 +N（仅显示总浏览数），避免列表噪音

- **涉及文件列表**：
  - backend/blog-article/src/main/java/com/blog/article/service/ArticleService.java
  - frontend/pages/admin/posts.vue
  （预测性，开发时以 grep 实际定位为准）

- **验证清单**：
  - [ ] /articles/admin/all 返回每条记录含 viewCount3d，值 = 该文章 page_view 近3天 COUNT(*)
  - [ ] 无 page_view 记录的文章 viewCount3d = 0
  - [ ] 前端"浏览"列显示 50（+10）格式，+10 为绿色
  - [ ] 近3天新增为 0 时仅显示总浏览次数，不显示 +0
  - [ ] 与筛选/翻页/排序（阅读最多）组合时 viewCount3d 正常
  - [ ] 前端构建 + 后端编译通过
- **完成时间**：2026-08-01 18:24:00
- **解决方案**：
  1. 后端 `ArticleService.adminList` 在 `fillAttachmentCounts` 后新增 `fillViewCount3d(records)`：
     一条 `SELECT article_id AS aid, COUNT(*) AS cnt FROM page_view WHERE article_id IS NOT NULL AND article_id IN (...) AND visit_date >= ? GROUP BY article_id`，
     JdbcTemplate + LocalDate 传参（跨方言），按 article_id in-memory merge，无记录兜底 0

     +N 绿色 `var(--success, #16a34a)`，+0 时隐藏（用户确认决策点②）
