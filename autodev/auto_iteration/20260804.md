## BUG项

### 20260804-BUG-001 分类与标签文章计数不一致问题修复

- **优先级**：高
- **状态**：✅ 已完成
- **完成时间**：2026-08-04 23:30:00
- **涉及文件列表**：
  - `backend/blog-article/src/main/java/com/blog/article/entity/Category.java`
  - `backend/blog-article/src/main/java/com/blog/article/service/ArticleService.java`
- **根因分析与描述**：
  - 后端 `/articles/categories` 接口只返回了分类基础数据，未统计与填充 `articleCount` 字段，导致公开分类页中各分类的文章数全部退化显示为 0。
  - 标签接口 `tags()` 的文章数统计未过滤 `deleted = 0 AND status = 1`（包含了软删与草稿文章）。
- **修复建议**：
  - 修改 `backend/blog-article/src/main/java/com/blog/article/service/ArticleService.java`：
    - `categories()` 方法中增加 `SELECT category_id AS cid, COUNT(*) AS cnt FROM article WHERE deleted = 0 AND status = 1 GROUP BY category_id` 查询，并充填至返回列表的 `articleCount` 字段中。
    - `tags()` 方法中将关联统计 SQL 加上 `JOIN article a ON at.article_id = a.id WHERE a.deleted = 0 AND a.status = 1` 过滤，确保数字与前台展现的已发布文章数完全匹配。
- **验证清单**：
  - [x] 访问 `/articles/categories` 接口，各分类对象包含正确的 `articleCount` 字段且仅统计已发布未删除的文章。
  - [x] 前端 `/categories` 页面各分类卡片显示的数字与实际点击后拉取的文章总数完全一致。
  - [x] 前端 `/tags` 页面各标签卡片显示的数字与前台已发布文章数完全一致。
