维护约定 HOW

这套图是给"自己半年后回来快速定位"的活文档。下面的约定保证单图升级不会拖累 index，统一修一两行即可。

新增功能逻辑图
复制最近一张图的 HTML → 改文件名 YYYY-MM-DD-{slug}.html → 在 index.html 网格加一张卡片（复制现有 card 节点）。
更新现有图
跨模块重构 / 关键 BUG 修复 → 改对应图的 mermaid + decision card；卡片 metrics（决策点数 / 场景数 / 文件数）在本 index 同步更新。
颜色 / 字号统一
所有图共用同一套 CSS 变量（在 :root）。批量调字号：写一次性 Python 脚本扫 8 个文件替换 font-size: NX 数值；不要一个一个 Edit 改。
归档位置
所有图统一在 autodev/auto_iteration/img/。跨项目可复制：CSS 完全独立不依赖项目代码。
