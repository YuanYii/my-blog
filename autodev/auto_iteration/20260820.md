### 20260820-DEV-001 仅链接可见文章 (Unlisted Post) 全链路实现与权限隔离

- **优先级**：高 (P1)
- **状态**：✅ 已完成
- **完成时间**：2026-08-20 09:45:00
- **涉及文件**：
  - `backend/blog-app/src/main/java/com/blog/common/security/AdminAuthFilter.java`
  - `backend/blog-article/src/main/java/com/blog/article/entity/Article.java`

  - `backend/blog-article/src/main/java/com/blog/article/service/ArticleService.java`

  - `frontend/assets/css/main.css`

- **根因分析与需求描述**：
  - 博客需要支持一种“未公开列出 / 仅链接可见”文章类型（`status = 3`）：普通访客在首页无法看到该文章；管理员登录后可在首页看到带有 `🔗 仅链接可见` 专属徽章的文章；任何人只要获得 `/post/{slug}` 链接均可直接打开阅读；搜索引擎、Sitemap、归档和分类统计严格隔离防泄露。
- **详细实现方案**：
  1. 后端鉴权感知：`AdminAuthFilter.java` 针对公开 GET 请求提供可选 Bearer Token 解析 (`tryOptionalAuth`)，管理员登录态写入 `AuthContext`。
  2. 列表与详情流转：`ArticleService.java` 中 `list()` 动态根据管理员登录态查询 `status IN (1, 3)`（普通访客仅 `status = 1`）；`detail(slug)` 支持 `status IN (1, 3)` 链接直达；`create()` 与 `update()` 支持 `status = 3` 校验与保存；`toPublicMap` 包含 `status` 字段。
  3. 前端界面与防爬虫：
     - `index.vue` 引入 `useAuth()` 登录态，管理员已登录时请求列表附带 Token，为 `status === 3` 卡片渲染 `🔗 仅链接可见` 徽章。
     - `post/[slug].vue` 当 `status === 3` 时使用 `useHead` 注入 `<meta name="robots" content="noindex, nofollow" />`，并在顶部展示仅链接提示条。
     - `admin/edit.vue` 状态组增加「仅链接」选项（value: 3）；`admin/posts.vue` 增加对应状态徽章与筛选支持。
  4. 测试与验证：在 `ArticleControllerTest.java` 中增加权限与隔离单测（72/72 PASS）；在 `verify-sqlite.sh` 中增加端到端测试链路（35/35 PASS）。
- **验证清单**：

  - [x] 访客与管理员直接通过 `/post/{slug}` 均可正常访问正文

  - [x] Sitemap / Archives / Categories / Tags 严格隔离隐藏文章
