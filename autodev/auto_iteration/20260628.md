### 20260628-DEV-001  | 中 | ✅ 已完成

- **开发内容**：
  全站"确认/取消"按钮增加键盘快捷键支持：Enter 触发确认、Esc 触发取消。
  范围覆盖：所有 $dialog.confirm / $dialog.prompt 弹窗 + admin 后台内联表单/Modal
  的取消/确认按钮。

  当前实现状态：
  - `GlobalDialog.vue` 已有 Esc 关闭（keydown 监听 + handleCancel），但不支持 Enter 确认
  - `PasswordForm.vue` 输入框已有 `@keyup.enter`，属个别实现
  - 其余 admin 页面（posts / comments / categories / tags / devices / backup /
    restore / settings 等）的"确认/取消"按钮均无键盘快捷键

  子项：
  1. **GlobalDialog 新增 Enter 触发确认**：在 `onKeydown` 监听里追加
     `e.key === 'Enter' && !e.isComposing` 分支，调 handleConfirm；confirm 模式下
     默认按钮被聚焦时也支持 Enter。需处理 IME 中文输入法 composing 状态（回车上屏
     不应触发确认）。
  2. **GlobalDialog 强化 Esc**：当前实现已可用，但需 review 嵌套 Dialog、焦点
     转移、IME 状态时的行为。
  3. **admin 内联表单/页面按钮 review**：扫描所有 `<button>` 标签的"确认/取消"按
     钮（如 `pages/admin/restore.vue` 的「确认恢复」「取消」`pages/admin/categories.vue`
     的「取消」「确认」`pages/admin/posts.vue` 的「取消」等），按需加 @keyup.enter
     / Esc 监听（Modal 内 form 提交 + 自定义按钮的组合需要 case-by-case 处理）。
  4. **可访问性 (a11y)**：确认按钮自动聚焦（autofocus），Tab 键能在确认/取消间切换，
     Enter 触发主按钮（primary），Esc 触发取消。
  5. **不影响表单内回车**：纯表单提交场景（如创建文章、保存设置）已有原生
     `<form @submit>` 行为，不在此次需求范围内（除非用户后续明确）。

- **开发建议**：
  - 主战场是 `frontend/components/GlobalDialog.vue`：
    - 在 `onKeydown` 里加 `e.key === 'Enter'` 分支：
      ```ts
      if (e.key === 'Enter' && props.open && !e.isComposing && !e.shiftKey) {
        e.preventDefault()
        handleConfirm()
      }
      ```
    - `e.isComposing` 用于排除 IME 输入法 composing 状态（中文回车上屏）
    - `e.shiftKey` 排除 Shift+Enter（多行输入场景，虽然本 Dialog 不直接支持但保留）
  - 确认按钮在 Dialog 打开时 `nextTick` 后调用 `confirmButtonRef.value?.focus()`，
    使 Enter 直接落在主按钮上
  - `useDialog.ts` 不需改（composable 不直接绑键盘事件，事件在组件层处理）
  - 内联按钮 review：建议优先在 Modal/Dialog 容器组件上统一挂 keydown 监听（事
    件代理），避免逐个按钮加 @keyup；如不可行再 case-by-case
  - 自动化测试：`frontend/tests/` 下用 Playwright 加 e2e 用例验证「打开 Dialog →
    按 Enter → 触发确认」「按 Esc → 触发取消」

- **涉及文件列表**：
  - `frontend/components/GlobalDialog.vue`（核心改动：Enter 监听 + 焦点管理）
  - `frontend/composables/useDialog.ts`（可能需调整：暴露 isComposing 透传）
  - `frontend/layouts/admin.vue`（admin 全局 Modal 挂载点，可能需事件代理）
  - `frontend/pages/admin/restore.vue`、`categories.vue`、`posts.vue`、

  - `frontend/tests/e2e/dialog-keyboard.spec.ts`（新增 e2e 测试）
